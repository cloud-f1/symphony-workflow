## Implementation plan — ADLC-43: `docs/plans/<NNNN>-<slug>/` convention

**Approach.** Replace the one-off `docs/{intent,spec,plan}.md` trio with a repeatable, ADR-style convention: `docs/plans/<NNNN>-<slug>/{intent,spec,implement}.md` per planning cycle — sequential, zero-padded (4 digits), never reused/renumbered, and `implement.md` instead of `plan.md` specifically to stop colliding with Claude Code's own `~/.claude/plans/*.md` scratch files (the exact loss this ticket exists to prevent). Add `docs/plans/INDEX.md` as the entry point, listing every cycle folder with a one-line summary and status.

**Migration.**
- `git mv docs/intent.md docs/plans/0001-symphony-poc/intent.md` (and same for `spec.md`; `docs/plan.md` → `.../implement.md`, a rename not just a move) — preserves git history.
- New `docs/plans/INDEX.md` with a header explaining the numbering rule and a row for `0001-symphony-poc` (Epic `ADLC-2`, Phases 0-5, Done).
- `docs/WORKFLOW.md` and `docs/PORTABILITY.md` stay put — they're cross-cycle policy/reference docs, not one cycle's intent/spec/design. `docs/runs/<ISSUE-KEY>/{plan,review}.md` also stays as-is — a separate, pre-existing per-*run* (not per-planning-cycle) convention; worth a one-line disambiguation note in `INDEX.md` since it also has a `plan.md`.

**Reference updates (found via repo-wide grep, broader than the ticket's own named list).** Beyond the ticket's named `CLAUDE.md` + `jira-agent-cli-ops` skill + `docs/PORTABILITY.md`, the grep turned up ~10 more files with dead-link risk: `docs/context/session-summary.md`, `docs/WORKFLOW.md`, and comment-only references in `agent_runner.py`, `api.py`, `orchestrator.py`, `poller.py`, `prompts.py`, `runs.py`, `workspace.py`, `test_agent_runner.py`, `test_runs.py`. All are mechanical path substitutions with no logic change. `CLAUDE.md`'s Project Overview paragraph also needs new prose describing the convention itself (pointing at `docs/plans/INDEX.md`), not just updated links, so this doesn't regress the next time a cycle starts.

**Risks/open questions:** (1) scope creep — ticket names 3 files, actual fix touches ~15; recommend doing all of them in one PR rather than leaving dangling links. (2) no automated enforcement of "next number = max+1" — manual discipline only, acceptable at this repo's scale. (3) whether `docs/WORKFLOW.md` should eventually join this convention is left open/out of scope. Verification: post-move `grep` for the old paths should return zero hits outside `docs/plans/0001-symphony-poc/` and `docs/runs/**`, plus a green `uv run pytest` (docs-only change, no new test coverage needed).
